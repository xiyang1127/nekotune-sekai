# Project SEKAI 音源插件

移植原 `sekai-music` TypeScript 库中目录与资源解析部分（`catalog.cpp`），提供 JP / EN / CN / TW / KR 五区歌曲浏览、作者与歌手搜索、演唱类型筛选、独立版本播放、加入队列及下载到本地曲库。界面支持中英文与 NekoTune 深色主题。

## 安装

1. 在 NekoTune「扩展」中导入 `build/packages/` 下的世界计划安装包，启用并确认信任。
2. 在侧栏「世界计划」选择区服，点击「搜索 / 浏览」。搜索框留空可浏览该区服全部演唱版本，无需配置数据源。

默认使用 sekai-music 包的数据源，激活插件不会立即加载曲库，浏览或播放时才请求上游。设置页只展示区服和音频偏好；需要自定义镜像时展开「高级设置」。地址留空会自动恢复默认值。主数据及音频地址填写到根目录，封面地址填写到桶目录；地址不支持内嵌凭据、查询参数或片段。

1.0.1 会自动迁移 1.0.0 的空地址和多余联网开关，保留已有自定义地址、区服与音频偏好。停用整个插件仍通过宿主「扩展」页面操作。

歌曲单击选中，双击或 Enter 播放。「入队」不切歌，「下载」不修改队列。下载进度与取消使用宿主服务，完成后进入本地曲库。

1.1.1 起，音频入库后会自动保存同目录同名的 `.webp`、`.png` 或 `.jpg` 封面；曲库和播放器通过宿主统一的 `cover_url` 使用本地文件，离线仍可显示。先尝试封面镜像，再尝试所选区服与允许的日服候选；响应须符合图片格式、尺寸和 5 MiB 大小限制。已有封面不会覆盖，重复下载可补充缺失封面。封面失败不撤销音频入库，界面会显示提示。

## 歌曲与资源语义

1.1.2 起，下载完成时会保存同目录同名的 `.lrc`，默认内容为「暂无歌词」。游戏剪辑版与普通发行版的歌词时间轴不一致，因此使用本地默认歌词阻止播放器自动匹配其他版本；刷新歌词仍优先使用本地文件。已有 LRC、KRC 或手动填写的歌词会保留，之后仍可手动选择或编辑歌词。重复下载可补充缺失的默认歌词，保存失败会提示但不撤销音频入库。

- 每页 40 个演唱版本，按歌曲 ID 从新到旧排序；可搜索歌名、作曲／作词／编曲、版本名称、歌手和歌曲 ID。未知演唱类型保留并可筛选。
- 稳定 ID 为 `区服:vocalId:long|short`，例如 `jp:1185:long`。不同演唱版本、区服与短预览不会合并；切换默认区服或长度不会改变已保存曲目的身份。音频格式按当前设置解析。
- 搜索只读远端主数据，内存缓存 15 分钟；「刷新曲库」清除缓存。播放／下载前按所选版本验证音源，仅进行 HEAD 或最小 Range 探测，不批量验证整库。
- MP3 / FLAC / WAV 是否存在取决于上游。缺失资源与网络不可用分别提示。封面访问失败不会阻止音频解析，列表保留默认封面。
- `long` 是游戏长音频，不保证是原曲完整版。包没有歌曲时长和歌词接口，插件不伪造时长，也不注册歌词来源。
- 可关闭日服回退以严格使用所选区服音源。开启回退可能取得日服音频版本。

## 新下载的歌曲去除开头静音

1.1.0 默认开启「新下载的歌曲自动去掉开头静音」，可在设置中关闭。只影响新下载的长音频，短预览、在线播放与已有文件不变；宿主遇到已存在的下载文件时仍保留它。

处理依据实际音频检测：检查开头至少 12 秒，参考歌曲 `fillerSec` 延长检查范围（最多 30 秒），仅当从 0 秒开始的连续静音低于 -60 dB 且至少持续 0.5 秒、并观察到音乐开始时才裁切，保留约 30 毫秒缓冲。不会删除歌曲中间的停顿，也不固定切除 7–9 秒；没有确认到音乐起点时保留原音频。

MP3、WAV 等使用音频包直接复制，MP3 不做有损重编码；FLAC 重新无损编码以修正采样数和时长。处理后验证文件时长，再交由宿主计算最终 SHA-256、导入曲库。准备阶段可能比原下载多等一会儿，取消或失败会清理临时文件，不发布半成品。

此功能需要系统 PATH 中的 `ffmpeg` 和 `ffprobe`，本机已验证可用；不要求重新编译 NekoTune。缺少工具时会提示，可安装 FFmpeg 或关闭此选项。处理后的文件由宿主下载流程导入，不会修改已入库音频。

## 构建与开发

在外部插件根目录执行 `cmake -S . -B build && cmake --build build`。开发挂载请选 `build/extensions/nekotune.sekai/`，修改源码后重新构建即可自动重载。重新构建 ZIP 不会更新已安装副本，请在扩展页导入新 ZIP 并选择替换。

下载裁切片头静音需要系统 `PATH` 中的 `ffmpeg` 与 `ffprobe`。插件把音频下载到自身数据目录的 `audio-preparation/`，裁切并校验时长后交给宿主导入；临时文件在完成后或下次下载时清理。不再启动本地 HTTP 预处理服务。

## 验证

```sh
# 离线适配器测试（模拟网络；已安装 ffmpeg 时也验证 mp3/flac/wav 裁切）
ctest --test-dir build -R sekai_test --output-on-failure

# 宿主已构建时，运行专属 QML 交互测试
QT_QPA_PLATFORM=offscreen QT_QUICK_BACKEND=software \
  ../NekoTune/build/tests/nekotune_slider_quick_test -input tests/qml/tst_sekai.qml
```

原 `tests/sekai-smoke.mjs` 真实后端冒烟脚本依赖 Node 运行时，已随迁移移除；真实宿主加载由可选宿主测试工程覆盖（见[项目说明](../README.md)）。

离线测试、离屏截图和真实网络验证分别记录，不等同于人工听音或全库音频可用性保证。实现来源为用户提供的 `psjk/sekai-music` 包；上游行为说明见 [来源记录](../docs/sekai-music-upstream.md)。
